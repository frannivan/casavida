# 💰 Manual de Usuario: Recepción y Caja
> **Versión**: 1.0.4 | **Módulo**: Finanzas & Caja | **Rol**: Recepción / Contabilidad

---

## 1. Validación de Pagos (El Semáforo Contable)

Tu labor es asegurar que el flujo de efectivo digital coincida con la realidad bancaria.

1.  Ingresa a **[Caja]** > **[Validaciones Pendientes]**.
2.  Selecciona un registro de pago. El sistema mostrará el comprobante adjunto a la izquierda.
3.  **Protocolo de Cotejo**: Verifica que el **Monto** y la **Referencia** coincidan exactamente con tu banca en línea.
4.  Si los datos son correctos, presiona el botón verde **[Validar y Postear]**.

> [!CAUTION]
> **Seguridad Financiera**: Nunca valides un pago basado meramente en la imagen del comprobante. Siempre confirma el ingreso real de los fondos en la cuenta bancaria de la empresa.

## 2. Registro Manual de Pagos (Caja Física)

Para abonos realizados directamente en ventanilla:

1.  Utiliza el **[Buscador Global]** para localizar al cliente por nombre o número de lote.
2.  En la pestaña **[Pagos]**, haz clic en **[+ Registrar Abono]**.
3.  Define el **[Método de Pago]** (Efectivo, Terminal, Transferencia).
4.  **Confirmación**: Al guardar, el sistema emite automáticamente un **Recibo Digital** firmado al correo del cliente.

---

## 3. Manejo de Rechazos y Discrepancias

Si un pago subido por el cliente o vendedor tiene errores:

1.  Utiliza el botón **[Rechazar con Nota]**.
2.  Escribe una razón clara (Ej: "Comprobante ilegible" o "Monto incompleto").
3.  El sistema notificará al responsable para que suba la corrección de inmediato.

> [!NOTE]
> Todos los rechazos quedan registrados en el historial del cliente para futuras aclaraciones o auditorías.
