# 📊 Manual de Usuario: Directivo y Reportes
> **Versión**: 1.0.4 | **Módulo**: Inteligencia de Negocio | **Rol**: Directivo / Gerencia

---

## 1. Dashboard Ejecutivo (Pulso del Negocio)

Al ingresar al ERP, la primera vista es el Dashboard de Reportes. Esta pantalla consolida los KPIs más importantes para la toma de decisiones.

1.  **Ventas Totales**: Visualiza el monto acumulado de contratos firmados.
2.  **Lotes Disponibles vs Vendidos**: Gráfica de pastel que muestra el avance del inventario.
3.  **Ingresos del Mes**: Flujo de caja real validado por tesorería.

> [!TIP]
> Puedes hacer clic en cualquier métrica del Dashboard para profundizar en el desglose detallado de los datos que la componen.

## 2. Exportación de Reportes para Juntas de Resultados

El sistema permite generar documentos listos para impresión o envío por correo.

1.  Navega a **[Herramientas]** > **[Reportes]**.
2.  Selecciona el tipo de informe: **[Inventario Global]**, **[Corte de Caja]** o **[Comisiones de Vendedores]**.
3.  Define el rango de fechas.
4.  Haz clic en el botón verde **[Exportar Excel]** para análisis de datos o en el botón rojo **[Descargar PDF]** para una versión formal con membrete.

---

## 3. Monitoreo de Metas Comerciales

*   **Ranking de Vendedores**: Identifica a los colaboradores con mayor tasa de conversión.
*   **Embudos de Venta (Funnel)**: Observa cuántos Prospectos se están convirtiendo en Oportunidades Reales y finalmente en Clientes.

> [!IMPORTANT]
> Los reportes directivos se alimentan de información validada por contabilidad. Si notas discrepancias, verifica primero la pestaña de **[Validaciones Pendientes]** en el módulo de Caja.
